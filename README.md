Customer Churn Prediction and Analytics
An end-to-end customer churn analytics and machine learning project that combines Python, SQL, Power BI, and Streamlit to identify customers who are likely to leave and help businesses improve retention.

Project Overview

Customer churn is a major challenge for subscription-based businesses because losing existing customers can reduce recurring revenue and increase acquisition costs.

This project analyzes customer demographics, service usage, contract details, billing behavior, and payment methods to:

Understand the main factors associated with customer churn

Identify high-risk customer segments

Build a machine learning model to predict churn

Create an interactive Power BI dashboard for business decision-making

Develop a Streamlit application for individual and batch predictions

Business Problem

The project addresses these questions:

Which customers are most likely to churn?

Which services and contract types are associated with higher churn?

How much monthly revenue is at risk?

Which customer segments should receive retention offers?

What actions can reduce churn?

Dataset

The project uses the Customer Churn dataset, which includes customer demographics, tenure, services, contract type, payment method, monthly charges, total charges, Internet Service, Senior Citizen, Multiple lines, Dependents, Partners, Online security, Device Protection, and churn status.
